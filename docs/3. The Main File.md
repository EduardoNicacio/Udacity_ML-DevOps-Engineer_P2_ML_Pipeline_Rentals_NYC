# The Main File

The pipeline is defined in the `main.py` file located in the root directory of the starter kit. This file already contains some boilerplate code, including the data download step. Your task is to develop the additional steps needed for the pipeline and incorporate them into the `main.py` file.

**Important Note**: The modeling in this project serves as a baseline. We have kept the data cleaning and modeling steps simple to emphasize the MLops aspects of the analysis. With further effort, you can significantly improve the model's performance on this dataset.

**Environment Setup Reminder**:

Follow the Workspace setup instructions in Starter Kit & Set Up. Use the supplied environment files as the starting point, and update each component’s dependencies as required by the project steps.

The Workspace notebook kernel and the environments used by MLflow components are separate. Add each component’s required dependencies to its own `conda.yml`; installing a package in the notebook kernel does not make it available to that component.

If a step fails, inspect its error and environment configuration before changing package versions.

**Local Execution**:

These classroom instructions assume you are using the Udacity Workspace. If you run the project on your own computer, follow the repository README for local environment setup and supported operating systems, including Windows/WSL guidance.
