# Project Overview

You are working for a property management company that rents rooms and properties for short stays across multiple platforms. Your task is to estimate the typical price for a given property by analyzing the prices of similar listings. The company receives new data in bulk every week, which requires the model to be retrained on the same weekly cadence. To support this workflow, you will build an **end-to-end, reusable machine learning pipeline** that enables automated retraining and deployment.

Throughout this project, you will work with a complete MLOps toolchain, including data ingestion, preprocessing, experiment tracking, model training, evaluation, and artifact management. The goal is not only to train a model, but to design a pipeline that can be **reliably re-run as new data becomes available**. By the end of the project, you will have implemented a production-oriented ML workflow that reflects real-world MLOps practices.
