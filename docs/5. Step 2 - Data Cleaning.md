This step will start from the `sample.csv` artifact and create a new artifact `clean_sample.csv` with the cleaned data.

### Step 2: Define Parameters and Implement the Cleaning Logic

Modify `src/basic_cleaning/run.py` and the `MLproject` file to specify the parameter types and descriptions.

Replace placeholder comments like INSERT TYPE HERE and INSERT DESCRIPTION HERE.

**Parameter types**:

- `input_artifact`, `output_artifact`, `output_type`, `output_description`: Python `str` in `run.py`; `string` in `MLproject`.
- `min_price`, `max_price`: `float` in both files.

In the `# YOUR CODE HERE` section, implement the data cleaning logic as in the notebook.

Use the provided logger to report the main cleaning operations, including loading the input, filtering price outliers, converting `last_review`, and saving/uploading the cleaned artifact. No exact message format or number of messages is required.

Make sure to:

1. Download the data from W&B.
2. Use `args.min_price` and `args.max_price` for filtering outliers.
3. Save the cleaned DataFrame as `clean_sample.csv`:

    ```python
    df.to_csv("clean_sample.csv", index=False)
    ```

    **Note**: Always use index=False to avoid unwanted index columns in the output.
4. Upload the artifact to W&B:

    ```python
    artifact = wandb.Artifact(
    args.output_artifact,
    type=args.output_type,
    description=args.output_description,
    )
    artifact.add_file("clean_sample.csv")
    run.log_artifact(artifact)
    ```

### Step 4: Add the Step to the Pipeline

Update your `main.py` to include the new step:

```python
if "basic_cleaning" in active_steps:
    _ = mlflow.run(
        os.path.join(hydra.utils.get_original_cwd(), "src", "basic_cleaning"),
        "main",
        parameters={
            "input_artifact": "sample.csv:latest",
            "output_artifact": "clean_sample.csv",
            "output_type": "clean_sample",
            "output_description": "Price outliers filtered and last_review converted; missing values retained",
            "min_price": config['etl']['min_price'],
            "max_price": config['etl']['max_price']
        },
    )
```

**Note**: Always specify an artifact version or alias like `"sample.csv:latest"`.

Using just `sample.csv` will trigger errors such as:

```bash
Attempted to fetch artifact without alias (e.g., "<artifact_name>:v3" or "<artifact_name>:latest")
```

### Step 5: Run the Pipeline and Verify

To run the entire pipeline, execute:

```bash
mlflow run .
```

To run **only the** `basic_cleaning` **step**, use:

```bash
mlflow run . -P steps="basic_cleaning"
```

After running the pipeline, go to your W&B dashboard and verify:

- A new artifact type `clean_sample` is created.
- The file `clean_sample.csv` is available under it.
