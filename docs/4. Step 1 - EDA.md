# Step 1: EDA

## Exploratory Data Analysis (EDA)

The goal of this section is to understand how the process of Exploratory Data Analysis (EDA) fits into a pipeline. In a real project, you would spend much more time here, but for this exercise, we will perform the essentials.

**Note**: Remember to add explanatory markdown cells in your notebook so that colleagues (or reviewers) can follow along easily.

### Step 1: Run the Download Step

The `main.py` script already includes the **download** step. Run the pipeline to fetch a sample of the data.

This will also upload it to **Weights & Biases (W&B)**:

```bash
mlflow run . -P steps=download
```

You will see a message similar to:

```bash
2021-03-12 15:44:39,840 Uploading sample.csv to Weights & Biases
```

This means the data is stored in W&B as the artifact sample.csv.

### Step 2: Create the EDA Notebook

Create a notebook named `EDA.ipynb` in the root of your cloned project repository, alongside `main.py` and `config.yaml`:

```bash
build-ml-pipeline-for-short-term-rental-prices/EDA.ipynb
```

In the Workspace notebook editor, select the `ml` Python kernel using the kernel selector in the top-right corner. The displayed Python patch version may vary.

Use this Workspace kernel directly; you do not need to launch a separate JupyterLab session with `mlflow run src/eda`.

Use Markdown cells to explain your exploration and cleaning decisions, including why missing values are retained during EDA and handled in the inference pipeline. Include code comments so that another person can follow your analysis.

If you are working locally, follow the repository README for environment and notebook launch instructions, and save the notebook in the same repository-root location.

### Step 3: Load the Dataset

Inside the notebook, fetch the artifact `sample.csv` from W&B and read it into pandas:

```python
import wandb
import pandas as pd

run = wandb.init(project="nyc_airbnb", group="eda", save_code=True)
local_path = wandb.use_artifact("sample.csv:latest").file()
df = pd.read_csv(local_path)
```

We use `save_code=True` so the notebook itself is uploaded and versioned in W&B.

### Step 4: Generate the Profile Report

Use **ydata-profiling** (the modern replacement for the deprecated **pandas-profiling**) to generate an EDA report:

```python
import ydata_profiling

profile = ydata_profiling.ProfileReport(df)
profile.to_notebook_iframe()
```

This will display the report directly in the notebook. Review the report and identify the following:

- Missing values in several columns.
- The column `last_review` is stored as a string instead of a datetime.
- Outliers in the `price` column (including zeros and extreme highs).

After discussing with stakeholders, we will restrict nightly prices to between `$10` and `$350`.

### Step 5: Apply Basic Fixes

We now apply two important fixes:

- Remove price outliers.
- Convert last_review to datetime.

```python
# Drop outliers
min_price = 10
max_price = 350
idx = df['price'].between(min_price, max_price)
df = df[idx].copy()

# Convert last_review to datetime
df['last_review'] = pd.to_datetime(df['last_review'])
```

**Note**: We are not imputing missing values here. Missing value handling will be performed later in the inference pipeline so that the system can manage them at prediction time.

### Step 6: Verify the Fixes

Either regenerate the profile report or simply inspect the DataFrame:

```python
df.info()
```

Confirm that:

- Prices are within the defined range.
- `last_review` is now of datetime type.

### Step 7: Finish and Save

End the W&B run:

```python
run.finish()
```
